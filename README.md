- **الماروني الداكن (Deep Maroon / Burgundy):** `#781D42` (الأزرار الرئيسية، علامات التمييز، أشرطة التقدم)

## 📋 محتويات الاستبيان
يتضمن الموقع **كافة الأسئلة الأصلية الواردة في ملف الـ PDF** بالإضافة إلى **أسئلة التحقق المضافة الخاصة بنموذج العمل (BMC)**:

1. **القسم الأول: الخلفية وطبيعة النشاط**
   - هل عندك تجربة حالية أو سابقة بالعمل داخل شركة أو مشروع؟ (من الـ PDF)
   - ما هو النشاط الأساسي لشركتك أو مكان عملك؟ (مضاف لاستهداف شرائح السوق)
   - كيف كانت أغلب المعلومات والمهام تنظم؟ (من الـ PDF)

2. **القسم الثاني: التحديات ونقاط الألم اليومية**
   - شكد وجود نظام إلكتروني منظم مهم لنجاح أي شركة أو مشروع؟ (مقياس 1-5) (من الـ PDF)
   - شكد واجهت مشكلة إن المعلومات تكون موزعة بين أكثر من مكان؟ (من الـ PDF)
   - أكثر المشاكل اللي ممكن تسببها إدارة العمل بدون نظام إلكتروني متكامل؟ (من الـ PDF)
   - صعوبة مطابقة مبالغ الدفع عند الاستلام (COD) مع شركات التوصيل وحساب الرواجع؟ (مضاف لقياس تسرب الأموال)
   - أكبر عقبة في إدارة البيع بالأقساط؟ (مضاف لاختبار محرك الأقساط العراقي)
   - أكثر الأشياء اللي تخلي الموظف ما يحب يستخدم نظام إداري؟ (من الـ PDF)

3. **القسم الثالث: تقييم الحلول والميزات الذكية**
   - أهمية قابلية النظام للتخصيص والتكيف مع طبيعة عمل كل شركة؟ (مقياس 1-5) (من الـ PDF)
   - فائدة مساعد الذكاء الاصطناعي بالعربي للتدقيق والاستعلام؟ (مقياس 1-5) (من الـ PDF)
   - الشيء الأهم بالنسبة إلك بنظام الإدارة؟ (من الـ PDF)
   - النموذج المالي المفضل (اشتراك SaaS، تهيئة وتخصيص، شراء ترخيص)؟ (مضاف لاختبار مصادر الإيرادات)

4. **القسم الرابع: رؤيتك والتواصل**
   - أهم شيء لازم يتوفر لتسهيل شغل الموظف بدل زيادة التعقيد؟ (نص مفتوح) (من الـ PDF)
   - ما الذي ستغيره في طريقة إدارة العمل داخل الشركات؟ (نص مفتوح) (من الـ PDF)
   - رقم الهاتف أو اسم المتجر (اختياري) (من الـ PDF)

- أو تشغيل خادم محلي:

